# DCC 수위 추정 프로젝트

2026 데이터·AI 크리에이터 캠프 고등부 예선 과제를 위한 프로젝트이다. 수위표가 포함된 이미지를 분석하여 실제 수위를 미터(m) 단위의 연속값으로 예측하는 것을 목표로 한다.

## 프로젝트 목표

- AI-Hub 수위 측정 데이터의 구조와 품질 분석
- 목자판 8종 및 방해물 분포 확인
- 목자판 바운딩박스 시각화
- 유사한 촬영 장면으로 인한 데이터 누수를 줄이는 데이터 분할
- 이미지와 목자판 종류를 이용한 수위 회귀 모델 개발
- 전체 및 목자판 종류별 RMSE 평가
- 오차가 큰 이미지와 성능 저하 요인 분석

## 문제 정의

수위 추정을 연속값 회귀 문제로 정의하였다.

- 입력: 수위 측정 이미지, 파일명 첫 글자에서 얻은 목자판 종류
- 출력: 미터(m) 단위의 예측 수위
- 평가 지표: RMSE

목자판 종류는 `A`, `B`, `C`, `E`, `F`, `G`, `H`, `S`의 8종이다. 테스트 과정에서는 이미지와 파일명 첫 글자만 사용하며, JSON의 실제 수위와 위치 정보는 예측에 사용하지 않는다.

## 데이터

AI-Hub의 수위 측정 데이터 중 다음 Training 데이터를 사용한다.

- 원천 이미지: 308,085개
- JSON 라벨: 308,085개
- 이미지와 JSON의 누락된 대응 쌍: 0개

동일 장소 또는 연속 촬영 장면으로 추정되는 유사 이미지가 Train과 Test에 동시에 포함되면 모델의 일반화 성능이 과대평가될 수 있다. 이를 줄이기 위해 perceptual hash 기반으로 유사 이미지를 그룹화한 뒤 그룹 단위로 Train, Validation, Test를 약 8:1:1로 분할한다.

> AI-Hub 원본 데이터와 실험용 데이터 ZIP은 용량 및 이용 조건으로 인해 이 저장소에 포함하지 않는다. 실행하려면 AI-Hub에서 데이터를 별도로 내려받아야 한다.

## 모델

다음 모델을 동일한 조건에서 비교 대상으로 설정하였다.

- ResNet50
- EfficientNet-B0
- ConvNeXt-Tiny

기본 모델은 Colab 환경에서 반복 실험하기 비교적 가벼운 EfficientNet-B0이다. 이미지 특징과 목자판 종류 임베딩을 결합하여 수위를 예측한다. 최종 모델은 실제 Validation RMSE를 비교한 뒤 결정한다.

## Google Colab 실행

1. 통합 노트북을 Google Colab에 업로드한다.
2. `런타임 > 런타임 유형 변경`에서 GPU를 선택한다.
3. Google Drive를 연결한다.
4. 데이터 ZIP을 `/content`에 압축 해제한다.
5. 노트북의 `IMAGE_DIR`, `LABEL_DIR`, `OUTPUT_DIR`를 실제 경로로 수정한다.
6. 위쪽 셀부터 순서대로 실행한다.

실험용 4,000장 ZIP을 사용하는 경우의 경로는 다음과 같다.

```python
IMAGE_DIR = "/content/DCC_experiment_4000/images"
LABEL_DIR = "/content/DCC_experiment_4000/labels"
```

실험용 데이터는 코드 작동 확인 및 소규모 학습에만 사용한다. 최종 성능은 전체 데이터 또는 충분한 규모의 데이터로 다시 학습하고 평가해야 한다.

최종 평가에서는 다음 결과를 함께 확인한다.

- 목자판 8종별 RMSE
- 수위 구간별 RMSE
- 방해물 종류별 RMSE
- 절대오차가 큰 이미지 사례

반사광, 야간 촬영, 탁류, 거센 물살, 가림, 표면 오염 및 목자판 크기 등이 성능에 미치는 영향을 분석한다.

## 주의 사항

- 테스트 JSON의 실제 수위, 목자판 바운딩박스 및 수면 위치는 모델 입력에 사용하지 않는다.
- Test 데이터는 최종 모델을 선택한 후 한 번만 평가한다.
- 실제로 측정하지 않은 성능 수치는 보고서에 기재하지 않는다.
- 원본 데이터와 대용량 모델 파일은 GitHub에 업로드하지 않는다.
